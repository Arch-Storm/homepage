---
title: n8n
description: n8n Widget Configuration
---

Learn more about [n8n](https://n8n.io/).

Displays statistics about your n8n instance, including workflows, credentials, and executions.

Generate an API key in your n8n dashboard under Settings > n8n API.

```yaml
widget:
  type: n8n
  url: http://n8n.host.or.ip
  key: your-api-key
```
